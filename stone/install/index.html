# ==============================================================================

    $ cat /etc/preflight_check.log

    KERNEL WARNING: PERMANENT STORAGE WIPING

    Backup all personal data to off-device storage before running format steps. Internal user data (/data) will be completely erased.

    • Clean Flash Rule: Mandatory when switching from MIUI/HyperOS or another ROM base.
    • Firmware Level: Must be on the latest official vendor MIUI/HyperOS release for your region.
    • Recovery Binary: Flash and execute exclusively using AOSP recovery.

    HARDWARE INTERRUPTS: RECOVERY NAVIGATION

    In AOSP recovery mode: use Volume Up / Down keys to change selector position, and Power to commit selection.

    $ run --step 01..07

    [STEP 01] $ adb reboot bootloader

    Power off the device and hold [Vol Down] + [Power], or run from terminal: 

    adb reboot bootloader

    [STEP 02] $ fastboot flash boot boot.img

    Flash the recommended recovery boot partition image: 

    fastboot flash boot boot.img

    [STEP 03] $ fastboot reboot recovery

    Reboot the device directly into the newly flashed recovery environment: 

    fastboot reboot recovery

    [STEP 04] Recovery > Factory Reset > Format Data

    In the AOSP recovery menu interface: 

    Factory Reset > Format data / factory reset > Confirm

    [STEP 05] Recovery > Apply Update > Apply from ADB

    In recovery menu, select: 

    Apply update > Apply from ADB

    [STEP 06] $ adb sideload rom_package.zip

    Pipe and flash the build package over USB: 

    adb sideload rom_package.zip

    [STEP 07] $ fastboot reboot / Reboot System Now

    When the transfer finishes (Total xfer: 1.00x), navigate to main recovery menu and select: 

    Reboot system now
