    Installation Instructions — Redmi Note 12 5G / POCO X5 (stone)

    Follow these instructions carefully to flash Custom ROMs onto your device.

    ⚠️ Important Prerequisites

    Data Loss Warning

    Flashing a custom ROM requires formatting your internal storage. Backup all important documents, photos, and two-factor authenticator apps before proceeding!

    • Bootloader: Unlocked via Xiaomi Community / Mi Flash Unlock Tool.
    • Firmware: Ensure your device is on the latest official stock HyperOS/MIUI firmware for your regional variant.
    • Recommended Recovery: Official AOSP Recovery / Recommended Recovery provided with the build.
    • Computer Setup: Install official Android Platform Tools (ADB & Fastboot).

    Recovery Navigation

    Inside AOSP Recovery, use the ++volume-up++ / ++volume-down++ buttons to navigate options and the ++power++ button to confirm your selection.

    🚀 Flashing Process

    Use this method if you are coming from stock firmware or switching between different custom ROMs.

    Step 1: Boot into Fastboot

    Power off your device completely, then press and hold ++volume-down++ + ++power++ until the FASTBOOT screen appears.

    Alternatively, if booted into Android with USB Debugging enabled: 

    adb reboot bootloader

    Step 2: Flash Recovery

    Open a terminal on your computer in the folder containing your recovery image: 

    fastboot flash boot recovery.img

    Step 3: Reboot to Recovery

    Reboot directly into recovery mode: 

    fastboot reboot recovery

    Step 4: Format Data

    In recovery menu: 1. Select Factory Reset 2. Select Format data / factory reset and confirm.

    Step 5: Sideload the ROM

    1. In recovery, select Apply update ➔ Apply from ADB.
    2. Connect your phone to your computer via USB.
    3. In your terminal, run: 
      adb sideload <rom_filename>.zip
    4. (Optional) If flashing a Vanilla build and you require Google services, reboot back to recovery (Advanced ➔ Reboot to recovery), then sideload your GApps package: 
      adb sideload <gapps_filename>.zip

    Step 6: Reboot to System

    Return to the main recovery menu and select Reboot system now. First boot may take 2-3 minutes.

    Use this method only when updating to a newer build of the same ROM.

    1. Boot into recovery mode (press and hold ++volume-up++ + ++power++ while powering on).
    2. In recovery, select Apply update ➔ Apply from ADB.
    3. On your computer, sideload the update zip: 
      adb sideload <updated_rom_filename>.zip
    4. (Optional) If your ROM build requires manual GApps re-flashing:
    5. Go to Advanced ➔ Reboot to recovery.
    6. Select Apply from ADB and run adb sideload <gapps_filename>.zip.
    7. In the main menu, select Reboot system now. (Do NOT format data).

    🛠️ Need Help?

    If you run into issues or fastboot errors during installation, refer to our Troubleshooting Guide or ask in our Telegram Community.
